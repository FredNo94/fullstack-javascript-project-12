### Запуск

Локальные проверки изоляции состояния: `npm test` или `make test`.
Они проверяют независимость хранилищ между запусками, восстановление сессии,
выход и уведомления.

Установка зависимостей
```sh
npm ci
```

Запуск сервера и Vite в двух терминалах:

```sh
npm run server
```

```sh
npm run dev
```

Сборка и запуск приложения
```sh
make build
make start
```
